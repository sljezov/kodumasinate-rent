# Kodumasinate rent

Tarkvaraarenduse kavandamise kodutöö. Kavandatav veebirakendus aitab väikesel rendiettevõttel hallata kodumasinate saadavust, broneeringuid, väljastamist ja tagastamist. Klient saab sobiva seadme veebis broneerida.

## Projekti eesmärk

Asendada telefoni, e-kirjade ja tabelite abil peetav rendiarvestus ühe süsteemiga. Kõige olulisem tulemus on vältida sama seadme topeltbroneerimist ning anda töötajale ülevaade, milline seade on kliendi käes, vaba või hoolduses.

Esimese versiooni näidisseadmed on tekstiilipesurid, aurupuhastid ja tolmuimejad. Andmemudel võimaldab lisada ka teisi kodumasinaid.

## Töö seis

See repositoorium sisaldab kavandamise materjale. Rakendust ei ole programmeeritud ning arendus- ja testimistulemusi ei esitata tehtud tööna. Sprintide plaan kirjeldab tulevase arendusmeeskonna tööd. GitHubi tööde tahvel ja issue'd jälgivad kavandatud arendust; nende olekud ei tähenda, et funktsioonid on valmis.

## GitHub

Repositooriumi ja Projects-tahvli lingid lisatakse nende loomise järel. Kohalik diagramm tuleb avada diagrams.net-is käsuga **File → Open From → Device**.

## Eeldused

Üks rendipunkt, päevapõhine rent, klient tuleb seadmele ise järele ja tasub kohapeal. Veebimaksed, kojuvedu, pikaajalised lepingud ja raamatupidamisliidestus jäävad esimesest versioonist välja. Need on kavandamise eeldused, mida saab tellijaga täpsustada.
